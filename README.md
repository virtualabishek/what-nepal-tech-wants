# what-nepal-tech-wants

> Real tech job postings from Nepal — broken down so you know exactly what to learn.

Nepal IT jobs | Nepal developer jobs | Nepal tech hiring | tech stack Nepal | Nepal job requirements

---

A community-driven repo that takes real job postings from Nepali companies and breaks them down — what tools they use, what they actually expect, and how to learn each thing.

If you're a developer in Nepal trying to figure out what skills to build, or someone outside Nepal curious about the local tech scene, this is for you.

No fluff. No AI-generated filler. Just real jobs, real requirements, real explanations.

---

## Why this exists

Job descriptions are confusing. They list 15 technologies and you have no idea which ones matter, what level of knowledge they expect, or where to even start learning.

This repo takes those listings and does the work — reads them carefully, pulls out everything technical, explains what each piece is, and links to the right places to learn it.

It also serves as a growing map of what the Nepal tech industry actually uses in production. Useful for developers, students, and anyone trying to understand the local market.


Each job file has:
- Original job description (unchanged)
- Tech stack summary table
- Learning resources per topic
- Full breakdown — what each technology is and how to learn it
